
# IT Help Desk Analytics

## Project Overview
An end-to-end data analytics project analyzing 5,000 IT help desk tickets using Python, MySQL, SQL, and Power BI.

## Tools Used
- Python
- Pandas
- MySQL
- SQL
- Power BI

## Key Performance Indicators
- Total Tickets: 5,000
- Closed Tickets: 3,877
- Average Resolution Time: 12.30 hours
- Average Satisfaction: 4.48/5
- SLA Compliance: 61.52%
- Reopen Rate: 4.30%
- Escalation Rate: 8.02%

## Key Findings
- Network issues generated the highest ticket volume.
- Security issues had the longest average resolution time.
- Critical-priority tickets had the lowest SLA compliance.
- Customer satisfaction decreased as resolution time increased.

## Dashboard
The Power BI dashboard includes KPI cards, ticket trends, category analysis, SLA performance, resolution time, satisfaction, and interactive filters.
